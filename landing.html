What is ReviewLens

Star ratings hide the story. Reviews tell it.

A 4.2★ phone can still have a terrible battery. ReviewLens breaks every review into features, measures how people feel about each one, and flags reviews you shouldn't trust.

  • ✓Sentiment with a transparent score, not a black box
  • ✓Aspect-level insight: battery, camera, display, price and more
  • ✓Spam and rating-vs-text mismatch detection with reasons
  • ✓Side-by-side product comparison and buying recommendation

How it works

From raw text to insight in five steps

🧹

Clean

Normalise text, handle negation, emojis and contractions

💬

Sentiment

VADER + domain lexicon and a trained ML model

🧩

Aspects

Find features and score each one with evidence

🛡️

Spam check

Duplicates, shouting, promo links, rating mismatch

📊

Insights

Topics, SWOT summary and buying recommendation

Features

Everything you need to understand reviews

🎯

Aspect-based sentiment

See exactly which features customers praise or complain about, with the sentences that prove it.

🕵️

Fake review detection

Multi-signal checks flag spam, duplicates and suspicious patterns, and show the reason.

⚔️

Product comparison

Compare products on radar charts and get a transparent, weighted recommendation.

🧠

Topic discovery

TF-IDF keywords and LDA topics reveal what reviewers talk about most.

🧪

Live diagnostic lab

Paste any review and watch it get analysed in real time, with an explanation.

🔌

API, CLI and web app

Use it from Streamlit, a REST API with rate limiting, or the command line.
